## PDF 工具

依赖探测在 `probePdfTools()`：`pypdf`（合并/拆分/贴层；没有 PyPDF2 顶上）+ `reportlab`
（只用于水印 stamp 层）。没装就能力表明确说不可用。

| op | 输入 | 参数 | 产物 |
|---|---|---|---|
| merge | `messageIds` 2–20 份 PDF 文件消息 | 按给定顺序拼接 | 一个 PDF |
| split | `messageId` | `pages: "1-3,5"`（抽页成一个 PDF）或 `every: N`（每 N 页一拆），二选一 | PDF 或 ZIP |
| watermark | `messageId`（+图片水印再给 `watermarkMessageId`） | `text`（`\n` 多行）、`position` 九宫格/tile（全页防盗）、`fontSize` 8–144pt 或 `fontSizePct`=页宽 %（默认 5%，网页版对齐）、`color #RRGGBB` 或中文颜色词、`opacity` 0.01–1、`margin` 0–200pt、`rotation` ±180（正=顺时针）、`density` 1–20（tile 密度，越大越密，默认 5）；图片水印 `scale` 0.02–1。网页版"全页水印"配方：tile + rotation -20 + density 5 + opacity 0.12 + fontSizePct 5 | 一个 PDF |

- 水印实现：reportlab 按**首页尺寸**画一层 stamp（透明度用 setFillAlpha，图片用
  Pillow 预乘 alpha），pypdf 逐页 merge；页面尺寸不齐时等比缩放置中。
- 中文字体：reportlab 只吃 TrueType 轮廓，按候选列表逐个注册
  （wqy-zenhei → wqy-microhei → uming/ukai → simhei/msyh/simsun → DejaVu/arial）；
  全部失败且文字含非 ASCII 时如实报错。能力表 `watermark.font` 标注 `cjk-ok` 或缺失。
- 加密 PDF 一律拒绝（merge/split/watermark 都是），提示先解密。
- 页码解析 `parsePageRange("1-3,5")`：1 起始、支持中文逗号、去重保序、单次 ≤1000 页、
  运行时对页数校验超界。
- 产物落 `state/convert-out`（3 天保留），模型只拿 JSON 摘要。

## 二维码

引擎自动挑：`qrencode` CLI → Python `qrcode` 库 → Python `segno`；都没有就如实说。
参数：`level` L/M/Q/H（默认 M）、`scale` 1–20px（默认 6）、`margin` 0–16（默认 4）、
`dark`/`light` #RRGGBB。文本 ≤1000 字符，URL/WiFi/vCard 原样编码。
本机（Python 3.12 + qrcode 库）真跑通过：H 级、scale 8 → 513B 正方形 PNG。

## 批量图片处理

`qq_image_edit` 传 `messageIds`（2–12 张）+ 任意非 gif 动作 = 同一组参数逐张处理，
打包一个 ZIP 发回（`state/image-out`，`batch-<action>-<stamp>.zip`）；水印图片（watermarkMessageId）
对每张生效。第 N 张失败则整批失败并指明是哪张。一次批量算 1 次媒体额度。

## 服务器依赖（部署前确认）

```bash
python3 -c "import pypdf"        # PDF 合并/拆分/水印
python3 -c "import reportlab"    # 仅水印需要
which qrencode                   # 二维码（三选一）
python3 -c "import qrcode"       # 二维码备选
python3 -c "import segno"        # 二维码备选
# Debian/Ubuntu 参考：
#   apt install python3-pypdf python3-reportlab qrencode
#   （或 pip install pypdf reportlab qrcode）
```

注意：`python3-pypdf` 在老发行版可能没有，没有就 `pip install pypdf`；
Noto CJK 的 .otf 是 CFF 轮廓，reportlab 注册不了，中文字体请装 **fonts-wqy-zenhei**。
