# 通用文件格式转换（2026-10-27）

定位：用户私聊发一个文件 → 选目标格式 → 桥转换 → 以文件形式发回。
与 TTS 共用同一条身份规则：只私聊、token 必须属于该会话。额度（2026-10-28 定稿）：本地免费算力 → **不限次数**（config convert 段 0 = 不限，配正数才限）。

## 能力不是写死的，按服务器实际装的工具生成

`qq_convert_file` 不带 `target` 调用时返回本机能力表；模型必须先查再承诺。当前实现覆盖：

| 家族 | 依赖 | 输入 → 输出 |
|---|---|---|
| 音频 | ffmpeg | mp3/wav/m4a/aac/ogg/opus/flac/wma/amr → mp3/wav/m4a/aac/ogg/flac/wma |
| 视频 | ffmpeg | mp4/mkv/mov/webm/avi/flv → mp4/mkv/webm/gif，或抽 mp3/wav/m4a/aac/ogg/flac |
| 图片 | ffmpeg | png/jpg/jpeg/webp/gif/bmp/tiff → png/jpg/webp/gif/bmp/tiff |
| 图片→PDF | img2pdf（缺则退 Pillow） | png/jpg/webp/... → pdf；多图（2–50 张 messageIds）合成一个 PDF，可设 A4/Letter 页面 + 边距 |
| 图片→ICO | ImageMagick 或 Python Pillow | png/jpg/webp/gif/bmp/tiff → ico（256/128/64/48/32/16 多尺寸；方形补边；PNG 保留透明，JPEG 补白） |
| Office 文档 | LibreOffice | doc/docx/odt/rtf/txt/html → pdf/docx/odt/txt/html |
| 表格 | LibreOffice | xls/xlsm/xlsx/ods/csv → xlsx/ods/csv/pdf/html |
| 演示 | LibreOffice | ppt/pptx/odp → pdf/pptx/odp |
| PDF | poppler | pdf → txt（保留版式）、pdf → png/jpg（第一页） |
| Markdown | pandoc | md/html/txt/docx → md/html/txt/docx/odt |

视频的三个专用形态（都走 `qq_convert_file` 的 `options`）：
- **压缩**：目标写同格式（如 `mp4`→`mp4`）就是重编码压体积；`crf` 14–40、`level` low/medium/high（=32/26/20）、`maxHeight` 240–1440 限高、`mute` 去音轨。
- **转 GIF**：`start`（起始秒）、`duration`（≤60 秒，超了明确拒绝）、`fps` 1–30（默认 10）、`width` 64–1280（默认 480）；滤镜用 palettegen/paletteuse 两遍调色板，画质比裸 `fps=10` 好一截。
- **音频提取**：视频直接抽 mp3/m4a/wav/flac 等全族音频（`-vn` 重编码）。

明确不做：
- **PDF → docx**：版式必丢，转出来会被当成"转换坏了"；改提供 pdf→txt / pdf→png。
- **xlsm/docm 的宏保留**：宏一律禁用且丢弃（xlsm→xlsx 只保公式/值/格式）。
- 电子书（epub/mobi）、压缩包、CAD、字体等：没有可靠工具链，不承诺。

## 安全边界

1. 只私聊；群聊 403。
2. 输入 ≤50MB、输出 ≤150MB、超时 180s（视频 300s）；临时目录按 job 隔离，结束即删。
3. Office 文件先查 zip 解压总量（>300MB 拒绝，防 zip bomb）。
4. LibreOffice 用**独立临时配置 + MacroSecurityLevel=3**（宏不执行）；能用 `unshare -n` 就断网跑。
5. 全部 `spawnSync` 参数数组，不经过 shell；扩展名与目标格式都走白名单，不接受任意命令。
6. 产物留 `state/convert-out` 3 天；额度记 `state/convert-usage.json`。

## 服务器依赖（部署前确认）

```bash
which ffmpeg soffice pandoc pdftoppm pdftotext img2pdf unzip unshare
# Debian/Ubuntu 参考：
#   apt install ffmpeg libreoffice-writer libreoffice-calc libreoffice-impress \
#               pandoc poppler-utils img2pdf unzip fonts-wqy-zenhei
```

**中文字体是必须的**：没装 `fonts-wqy-zenhei`（或 Noto CJK）时，docx→pdf 的中文会变成方框。
LibreOffice 首次转换较慢（初始化配置），后续会快。

## 调用链

```
用户私聊发文件 → qq_convert_file(messageId, target)
  → console /api/convert
      · 从 NapCat get_msg 找 file 段 → 下载字节
      · 能力表校验 + 额度校验 + 大小校验
      · 临时目录转换（ffmpeg / soffice / pandoc / poppler）
      · 输出改名 → state/convert-out
      · upload_private_file 发回当前私聊
  ← 模型只拿到 JSON 摘要（from/to/bytes/ms），看不到文件字节
```

TTS 与转换的关系：TTS 已经直接支持 mp3/wav/m4a/ogg/flac；不需要"千问先给 mp3 再本地转"。
千问统一给 wav 源，桥只编码一次，避免多一次有损转码。用户上传的音频文件则走本转换器。

## 图片编辑（qq_image_edit）

依赖 **Python Pillow**（`python3-pil`）。没有 Pillow 时能力表会明确写不可用，不会假装能处理。

| 动作 | 参数 | 说明 |
|---|---|---|
| compress | `quality` 1-100、`targetKB`、`maxDim` | 按质量或目标 KB 压缩；targetKB 会迭代降质量 + 降尺寸 |
| resize | `width`、`height`、`mode` | fit=等比缩放+补边；crop=等比铺满+居中裁；stretch=直接拉伸 |
| crop | `crop=[x,y,w,h]` 或 `aspect="1:1"/"16:9"`，可选 `width/height` | 指定区域或按比例居中裁剪 |
| shape | `shape=circle/rounded/ellipse`、`radius`，可选 `width/height` | 圆形/圆角/椭圆遮罩；输出必须是 png/webp |
| watermark | `watermark{text,position,fontSize/fontSizePct,color,opacity,margin,rotation,density,tile}` 或 `watermarkMessageId` + `watermark{scale,rotation}` | 文字/图片水印；position 九宫格 + tile 平铺（全页防盗）；rotation ±180（正=顺时针，网页版默认 -20）；tile 密度 1~20 越大越密（默认 5）；fontSizePct=字号占图宽 %（默认 4%，网页版对齐）；可与 resize/crop 同一次调用叠加。颜色收 #RRGGBB 或常用中文词（红/蓝/金/灰…别名表在 `normalizeWatermarkColor`），认不出就报错指路，不瞎猜 |
| gif | `messageIds` 2-60 张 + `width` ≤1280 + `delay` 20-10000ms 或 `fps` 0.5-30（fps 优先） | 多图合成动图；帧 contain 到首页尺寸、白底合成；结果 >50MB 明确拒绝 |
| 批量 | `messageIds` 2-12 张 + 任意非 gif 动作 | 同一组参数逐张处理，打包一个 ZIP 发回；水印图对每张生效；第 N 张失败整批报错并指明；算 1 次额度 |

- 默认输出 `png`（保留透明），质量 85，`mode=fit`，圆角半径默认短边的 1/8。
- 图形裁剪拒绝 `jpg`：JPEG 没有透明通道，硬转会把遮罩外涂成黑/白。
- 非正方形图做圆形/椭圆裁剪时，先居中裁成正方形再上遮罩。
- **文字水印需要中文字体**：服务器没装 `fonts-wqy-zenhei` / Noto CJK 时，中文水印明确报错
  （提示装字体），不输出方框；纯英文/数字水印退 arial/DejaVu 可用。能力表的
  `watermark.font` 字段会写 `cjk-ok` 或 `missing-cjk-font`。
- 结果以**文件**发回，不发图片消息；QQ 图片消息会二次压缩，破坏刚做的压缩/边缘。
- 与文件转换同链路：**不限次数**（2026-10-28 定稿，本地免费算力）。
- 输入支持 QQ 图片消息（image 段）或图片文件（file 段），≤50MB。

## 文本 / JSON 工具（qq_text_tool，2026-10-27 晚）

纯字符操作，Node 内同步完成，不依赖 ffmpeg/Pillow；`src/core/text-tools.js`。

- 操作（16 个）：`json-format`（indent 2/4/tab/0 + sortKeys 深度排键）、`json-minify`、
  `json-validate`（报错到**行：列**）、`base64-encode/decode`、`url-encode/decode`、
  `hash`（md5/sha1/sha256/sha512）、`count`（码点/字节/行数/CJK/西文词）、`dedupe`、
  `sort-lines`（asc/desc/length + numeric）、`reverse-lines`、`upper`、`lower`、
  `trim-lines`、`replace`（字面或正则，默认全部）。
- 输入：`text` 直接传，或 `messageId`（文件消息按 UTF-8 读，≤2MB）。
- 输出：≤5000 字符内联返回（模型转述）；超过落 `state/convert-out` 成 .txt 以文件发回。
- 额度独立（2026-10-28 定稿）：**不限次数**（本地免费算力，config text 段 0 = 不限），
  记 `state/text-usage.json`；配置段 `text`。

## 验证

1. `node tools/test-file-convert.mjs`（56 项，能力表/计划/选项校验，不调用外部工具）。
2. `node tools/test-image-edit.mjs`（36 项；本机有 Pillow 时会真跑圆形裁剪、targetKB 压缩、
   比例裁剪、ICO、中文水印、3 帧合成 GIF、批量 3 张→ZIP）。
3. `node tools/test-text-tools.mjs`（36 项，纯函数全离线）。
4. PDF/二维码见 `PDF工具与二维码_20261027.md`（`test-pdf-tools` 21 项、`test-qrcode` 12 项）。
5. 服务器装上依赖后：`qq_convert_file` 不带 target，确认能力表里出现 docx→pdf / xlsm→xlsx / mp3→flac。
6. 实转：20 行 docx→pdf（检查中文不是方框）；xlsm→xlsx（检查宏丢失、公式还在）；mp3→flac；pdf→png；
   mp4→mp4 带 level=low；mp4→gif 带 start/duration/fps/width；3 张图合成 PDF；mp4→m4a。
7. 图片：`qq_image_edit` 不带 action 看能力；再试圆形头像、压缩到 500KB、16:9 裁剪、
   中文水印（右下 + tile）、3 张图合成 GIF、3 张图批量压缩成 ZIP。
8. 文本：`qq_text_tool` 不带 op 看能力；json-format 一个带错误的 JSON 验证行列提示；>5000 字符结果落文件。
9. 负面：51MB 文件、坏文件、加密 Office、群聊请求、GIF 超 60 秒、单帧合成 GIF、13 张批量，都应有明确人话。
