# TTS 千问复刻交付（2026-10-27，第二轮）

定位：**一次性交付任务**。用户发音频文件 + 要读的文本，交付一个音频文件。
不做聊天语音气泡、不做试听气泡；群聊不可用。

## 与现有 MiMo 语音的边界

| | MiMo（现有） | 千问（本链路） |
|---|---|---|
| 用途 | 聊天里回一条语音气泡 | 长文朗读 / 配音，交付音频文件 |
| 复刻方式 | 每次合成重传样本 DataURL（零样本） | 服务端建音色，返回 `voice_id`，之后只传 id |
| 状态 | `state/voice-config.json` + `state/voice-lib.json` | `config.json` 的 `voice.qwen` + `state/qwen-voices.json` |
| 入口 | `qq_send_voice` / 管理端语音页 | `tts_enroll_voice` / `tts_render_file` / `tts_voice_list` / `tts_voice_delete` |

两条链互不影响，MiMo 的默认音色、概率、额度都不变。

## 权限与额度（北京日 0 点刷新）

- 只对**私聊**开放；群聊一律 403（请求者无法可靠绑定，且最容易拿去冒充）。
- 主人（`ownerQQ`）：不限额。
- 普通用户：每天 **10 条**、**2,000 字**、**5 次建音色**、**3 个音色档案**（2026-10-28 定稿；全站池 12000 字 / 60 条 / 30 次建音色 = 单用户 600%）。
- 普通用户总池：每天 **20,000 字**、100 条、30 次建音色，防止多人叠加把账单打穿。
- 额度落 `state/tts-usage.json`；音色按 `ownerUid` 隔离，A 用户看不到/用不了/删不掉 B 用户的音色。

## 输出格式

默认 `mp3`；同一次交付可选：

| 格式 | 特点 |
|---|---|
| mp3 | 192k，兼容性最好，默认 |
| wav | PCM 16-bit / 44.1k，无损容器，文件大（10 分钟约 50MB） |
| flac | 无损压缩，文件约为 wav 的 40-60% |
| m4a | AAC 192k，苹果设备友好 |
| ogg | Opus/Vorbis 96k，小体积 |

千问统一返回 **wav** 源，桥侧只做一次编码；不采用“千问先给 mp3 再本地转”，因为那会多一次有损编码。

## 调用链

```
用户私聊发音频文件（wav/mp3/m4a，1-5 段，10-30s）
  → tts_enroll_voice(messageIds[], name?, consent=true)
      · 逐段质检打分，选最好的一段；>22s 挑 20s 最佳窗口
      · 转 24k 单声道 wav → Data URL → 千问 create_voice → 轮询 OK
      · 存 state/qwen-voices.json（ownerUid / consentAt / targetModel）
  → tts_render_file(voice, text, format?, title?)
      · 450 字分块 → 逐块 SpeechSynthesizer（44.1k wav，失败降级 24k）
      · 拼接（180ms 静音）→ loudnorm -16 LUFS → 目标格式 + AI 标记
      · upload_private_file 发回当前私聊
```

## 样本规矩

- **只收文件，不收语音气泡**：气泡是 silk 有损压缩；工具会明确拒绝。
- 5-60 秒可用，推荐 10-20 秒；>22 秒自动挑 20 秒窗口，优先从静音结束处起。
- ≥16kHz、单声道优先、无 BGM/噪音/第二人声、句中停顿 ≤2 秒、有效人声 ≥5 秒。
- 不合格返回具体原因，不是“样本无效”。
- 多段 = 多候选，不是多段训练；千问一个音色只吃一段样本。

## 成本（北京区域，官方价）

- 合成：`qwen-audio-3.1-tts-plus` **1.4 元/万字符**。
- 建音色：**0.01 元/次**。
- 10 条 × 20 字 ≈ **0.04 元**（复用音色）/ **0.13 元**（每条新音色）。
- 10 条 × 1000 字 ≈ **1.5 元**；10 条 × 3000 字 ≈ **4.3 元**（普通用户受 2000 字/天限制，实际单用户最多约 0.28 元/天）。

## 安全

- 只允许本人或明确授权的声音；`consent=true` 是硬参数，服务端拒绝缺失。
- 拒绝冒充公众人物、第三方或用于欺骗的内容。
- 交付文件带 `AI-generated voice (Qwen TTS)` 标记；不提供去标记/伪装真人的辅助。
- 样本与产物在 `state/tts-samples` / `state/tts-out`，保留 7 天；删音色时样本一起删。

1. **无需 workspaceId**：实测百炼 UID 当 maas 子域名报 400 IllegalEndpoint；
   `voice.qwen.baseUrl` 直接配标准网关 `https://dashscope.aliyuncs.com/api/v1` 即可

2. **key 走 env**：`DASHSCOPE_API_KEY` 已写入服务器 `~/.config/qq-agent.env`
   （桥 systemd 单元的 EnvironmentFile，权限 600）。
3. **预设音色不可用**：cherry / longxiaochun / longwan 等预设名全被引擎 411 拒——
   引擎只认注册 voice_id，恰好与生产流程（先 enroll 后 render）一致，无需适配。

端到端五步已实证：create_voice → DEPLOYING → OK（数秒）→ SpeechSynthesizer（44.1k 直接受）→
OSS 音频 url（550KB RIFF 验真）→ delete_voice。建音色约 0.01 元。
服务器离线回归 7 套 231 项全绿（含本模块 26 项：`node tools/test-qwen-tts.mjs`，mock fetch，不联网）。
